## Why Scoutify?

<CardGrid>
  <Card title="⌘K Modal" icon="rocket">
    Drop-in Livewire global search modal with grouped results, accent-insensitive
    highlighting, and keyboard navigation out of the box.
  </Card>
  <Card title="Multi-driver" icon="setting">
    Works with Meilisearch, Algolia, Typesense, or the Database driver. Zero
    coupling to a specific Scout backend.
  </Card>
  <Card title="Fluent Authorization" icon="approve-check">
    Per-model visibility rules with a fluent builder. Policies, Gates, Spatie
    permissions and roles, custom callbacks.
  </Card>
  <Card title="Zero-config setup" icon="magnifier">
    `php artisan scoutify:install` provisions config, packages, env, and a
    starter searchable model.
  </Card>
</CardGrid>
