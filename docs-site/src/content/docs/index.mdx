## Why Scoutify?

<CardGrid>
  <Card title="⌘K Modal" icon="rocket">
    Drop-in Livewire global search modal with grouped results, accent-insensitive
    highlighting, and keyboard navigation out of the box.
  </Card>
  <Card title="Multi-driver" icon="setting">
    Works with Meilisearch, Algolia, Typesense, or the Database driver. Zero
    coupling to a specific Scout backend.
  </Card>
  <Card title="Fluent Authorization" icon="approve-check">
    Per-model visibility rules with a fluent builder. Policies, Gates, Spatie
    permissions and roles, custom callbacks.
  </Card>
  <Card title="File Preview" icon="document">
    Inline PDF, image, and video previews directly in the modal. Models expose a
    `PreviewDto` — Scoutify handles signed routes, streaming, and download events.
  </Card>
  <Card title="Artisan Ready" icon="laptop">
    `php artisan scoutify:install` provisions config, packages, env, and a
    starter searchable model. Zero-config deployment.
  </Card>
  <Card title="Highly Customizable" icon="pencil">
    Customize icons, colors, labels, and even the query builder per model using 
    standard Eloquent methods.
  </Card>
  <Card title="Production Tested" icon="starlight">
    Comprehensive test suite, PHPStan level 5 static analysis, and optimized for performance with large datasets.
  </Card>
</CardGrid>

## Quick taste

<Tabs>
<TabItem label="Model">

```php
namespace App\Models;

use Matheusmarnt\Scoutify\Concerns\Searchable;
use Matheusmarnt\Scoutify\Contracts\GloballySearchable;
use Illuminate\Database\Eloquent\Model;

class Article extends Model implements GloballySearchable
{
    use Searchable;

    public function globalSearchTitle(): string { return $this->title; }
    public function globalSearchUrl(): string { return route('articles.show', $this); }
}
```

</TabItem>
<TabItem label="Blade">

```blade
{{-- Root layout --}}
<livewire:scoutify::modal />

{{-- Header --}}
<x-scoutify::gs.trigger />
```

</TabItem>
</Tabs>
